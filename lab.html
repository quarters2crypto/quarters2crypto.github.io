incubating · Game / Narrative · Godot 4

TIME MACHINE

Premise: a 2D top-down narrative RPG with an SNES-era soul, set in a pre-flood ancient civilization. The world is already lost — your job is to understand why. Thirty to forty-five minute sessions, a branching state system, and a local AI narrative layer with no cloud dependency.

Current state: design phase. The project scaffold, specs, and system documents exist; the first playable slice is on the roadmap but not yet built, and there is no web-playable build today.

This spot is the integration slot. When the first playable web slice exists, it docks here. Needed to activate: an exported web build (or a web-native first slice) of the game. Until then, the slot stays honest rather than pretending to be a game.
